# Project Videos

Place your optimised `.mp4` project demo videos here (for local hosting).

> **For Google Drive links** — update the `video` field in `src/data/projects.js`
> with the format: `https://drive.google.com/file/d/YOUR_FILE_ID/preview`
> and set `videoType: "gdrive"`.

## Google Drive Setup

1. Upload your video to Google Drive
2. Right-click → Share → "Anyone with the link can view"
3. Copy the file ID from the URL: `https://drive.google.com/file/d/FILE_ID_HERE/view`
4. Set the `video` field to: `https://drive.google.com/file/d/FILE_ID_HERE/preview`
5. Set `videoType: "gdrive"` in `src/data/projects.js`

## If hosting locally

- Format: MP4 (H.264)
- Resolution: 720p or 1080p
- Length: 30–90 seconds
- Target size: 5–20 MB
- Compress with HandBrake (preset: Fast 1080p30)
